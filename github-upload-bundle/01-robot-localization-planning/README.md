# 🐕 移动机器狗无线电干扰源自主定位与清除系统

本目录收录了 2026 年数学建模竞赛中针对四足机器狗电磁干扰源排查的完整技术成果。

## 文件内容
- `无线电干扰源的快速自动定位与清除_论文终稿.pdf`：18页重构印刷级学术论文（纯正矢量公式渲染与15幅高清图表）
- `paper.tex`：标准 LaTeX CTeX 源码工程文件

## 算法核心
1. **半平面交与旋转卡壳**：$O(n_V)$ 复杂度求凸多边形直径；
2. **最小外接圆判据**：以 $R_{\text{mec}} \le 20\text{ m}$ 作为激光清除充要动作判据；
3. **Voronoi 布点与 2-opt 规划**：证明全域覆盖完备性，优化巡游路径；
4. **官方测试验证**：三次盲测干扰源清除率达 100%。
