## 🌟 核心项目速览

### 1. 移动机器狗无线电干扰源自主定位与清除系统
- **技术栈**：计算几何、半平面交（Sutherland-Hodgman）、旋转卡壳算法、最小外接圆覆盖（Welzl）、Voronoi 全域布点完备性证明、TSP 路径规划（最近邻 + 2-opt）
- **核心成果**：构建自适应降级搜索链，在官方模拟器三次盲测中达成 **100% 干扰源清除率**。
- **文件归档**：包含 18 页重构学术论文终稿 PDF 与 LaTeX 完整工程。

### 2. 基于 SG3525 的推挽式 DC-DC 隔离升压稳压电源
- **技术栈**：推挽拓扑（Push-Pull）、功率 MOSFET 驱动死区控制、TL431+PC817 隔离闭环稳压、0.1Ω 康铜丝采样 + LM393 硬件过流关断（Shutdown）
- **指标与交付**：12V 输入，24V/1A 标称可调稳压输出，手工焊接整板并完成闭环波形与保护响应实测。

### 3. 四路高精度复合模拟信号发生器（电赛国赛真题）
- **技术栈**：单电源 +2.5V 虚地偏置、弛张振荡器、二阶 Sallen-Key 有源滤波、全通移相网络、35×38 高密度洞洞板物理拓扑重构
- **核心突破**：攻克异型元件网格冲突与高频脉冲对模拟小信号串扰，将全板跨区绝缘飞线**极限精简至约 20 条**，在示波器 X-Y 模式下成功通过李萨如图形圆度完成 90° 正交特性标定。
