# 🎯 四路高精度复合模拟信号发生器（35×38 洞洞板优化工程）

本工程复现全国大学生电子设计竞赛综合测评国赛真题。在极其严苛的物理约束下，完成信号链设计与高密度洞洞板物理拓扑重构。

## 极限约束与信号链
- **芯片约束**：仅限 1 片 LM324（四运放）+ 1 片 SN74LS00（与非门）
- **供电约束**：单一 +5V 单电源供电（自主设计 +2.5V 虚地偏置网络）
- **四路输出**：
  - Uo1 (J1)：19~21kHz 连续调频方波（Vpp ≥ 3.2V）
  - Uo2 (J2)：5%~15% 占空比连续可调窄脉冲
  - Uo3 (J3)：同频低失真正弦波（失真度 < 5%，Vpp ≥ 1V）
  - Uo4 (J4)：90° 正交余弦波（相位误差 ≤ 5°）

## 物理布局与攻坚（核心技术壁垒）
1. **网格干涉攻坚**：完美解决 3362P 品字形电位器与 5.08mm 螺钉接线端子与 2.54mm 网格的干涉；
2. **抗串扰物理分区**：以双 IC 为轴设计顺时针流向，彻底隔离高频脉冲与高阻微弱正弦滤波节点；
3. **飞线极致精简**：最大化采用焊锡就近搭桥，将整板跨区绝缘飞线**极限控制在约 20 条**；
4. **测试端子一字出线**：右侧边缘一字排列 J1~J4 端子，消除引线电感并极大提升示波器实调工效。
