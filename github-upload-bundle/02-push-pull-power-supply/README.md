# ⚡ 基于 SG3525 的推挽式 DC-DC 隔离升压可调稳压电源

本电路用于机器人动力系统中高压执行机构与伺服舵机的功率供电。

## 核心指标
- **输入电压**：直流 12V / 3A 标称输入
- **输出规格**：直流 24V / 1A 标称稳压输出（输出电压连续可调，额定功率 24W）
- **拓扑结构**：推挽变换器（Push-Pull），原边中间抽头斩波，副边全波肖特基整流 + LC 储能滤波

## 硬件亮点
1. **死区防直通控制**：SG3525 硬件设置死区时间，驱动两只 IRF540 N-MOSFET；
2. **精密隔离稳压**：副边 TL431 精密基准 + PC817 光耦实现电压隔离闭环；
3. **硬件级过流自锁**：0.1Ω 康铜丝采样源极电流，LM393 比较器实现 0~4.5A 连续可调阈值，超载纳秒级拉高 SG3525 Pin 10（Shutdown）强制关断。
